## 📌 About This Repository

Welcome to my **DevOps with AWS** course repository!

This repository contains PDF files of course assignments, lab instructions, and related reports. It serves as a central place to organize practical exercises, document learning progress, and maintain a reference for DevOps and cloud deployment tasks.

The repository will be updated as new assignments and practical exercises are completed throughout the course.

## 🎯 Learning Objectives

- Understand cloud computing concepts and AWS services.
- Practice Linux commands and server administration.
- Learn containerization using Docker.
- Build CI/CD pipelines using Jenkins and related tools.
- Explore Kubernetes and container orchestration.
- Deploy and manage applications on AWS infrastructure.
- Understand application hosting, networking, and deployment workflows.
- Maintain organized technical documentation for practical tasks.

## 📚 Practical Areas

### 1. Linux & Server Administration
Working with Linux commands, file permissions, services, and server configuration.

### 2. Docker & Containerization
Building Docker images, running containers, configuring Docker Compose, and managing application environments.

### 3. CI/CD with Jenkins
Understanding automated build, test, and deployment workflows using Jenkins pipelines and GitHub integration.

### 4. Kubernetes
Exploring deployments, pods, services, and multi-node cluster concepts.

### 5. AWS Cloud Deployment
Deploying applications on AWS infrastructure, including EC2 instances, and configuring applications for access through a public endpoint when appropriate.

## 🚀 Repository Goals

- Keep all course task PDFs organized in one place.
- Track progress through practical DevOps exercises.
- Maintain a reference for commands, configurations, and deployment procedures.
- Demonstrate hands-on learning in cloud computing and DevOps.
- Build a technical learning portfolio for future opportunities.
