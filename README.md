# DevOps with AWS — Course Tasks

This repository contains assignments, lab manuals, and practical tasks completed as part of a DevOps course focused on Amazon Web Services (AWS) and modern DevOps tools.

## Objectives
- Learn and practice DevOps concepts through hands-on tasks.
- Understand Linux administration and cloud infrastructure.
- Work with Docker, Jenkins, Kubernetes, and CI/CD pipelines.
- Deploy and manage applications on AWS.
- Maintain organized documentation of course assignments and practical exercises.

## Repository Contents
Each task is organized separately and includes the relevant PDF instructions and, where applicable, implementation files, commands, screenshots, and documentation.

## Purpose
This repository serves as a learning portfolio and reference for tracking progress in DevOps, cloud computing, automation, and application deployment.

**Note:** The repository contents will be updated as new course tasks are completed.
